# BIL 476 — Diabetes Risk Classification Project

Classification project comparing Decision Tree, Naive Bayes, k-NN, Random Forest,
AdaBoost, XGBoost, and LightGBM on the CDC BRFSS 2015 Diabetes Health Indicators
dataset, each with and without SMOTE class-imbalance handling, both with fixed
and Optuna-tuned hyperparameters. The best-performing configuration is then
retrained on the full 253,680-row dataset (not just the 40k stratified sample
used for model selection) as the final model.

## Setup

```
pip install -r requirements.txt
```

Python 3.10+ recommended. Random seed fixed to 42 everywhere for reproducibility.

## Data

`src/00_data_load.ipynb` downloads the dataset automatically via `kagglehub`
(requires a free Kaggle account/API key — see [data/README.md](data/README.md)
for setup and a manual-download alternative). The raw CSV is not included in
this repository.

## Pipeline

Run the notebooks in `src/` in order, using Jupyter Notebook/Lab, VS Code, or
Google Colab. Each notebook must be run to completion before the next one,
since each reads CSV/model files saved by the previous step.

```
cd src
jupyter notebook
```

Then open and run, in order: `00_data_load.ipynb` → `01_eda.ipynb` →
`01b_feature_engineering.ipynb` → `02_preprocessing.ipynb` →
`03_train_models.ipynb` → `03b_hyperparameter_tuning.ipynb` →
`04_evaluate_compare.ipynb` → `05_final_model_full_data.ipynb`.

| Notebook | Purpose | Key outputs |
|---|---|---|
| `00_data_load.ipynb` | Downloads the dataset from Kaggle via `kagglehub` and places it where the pipeline expects it | `data/diabetes_binary_health_indicators_BRFSS2015.csv` |
| `01_eda.ipynb` | Loads raw CSV, checks missing values, takes a stratified 40k-row sample, documents each feature's meaning, plots per-feature and target-relationship distributions, plots class distribution and correlation heatmap | `data/diabetes_sampled.csv`, `data/descriptive_stats.csv`, `figures/*.png` |
| `01b_feature_engineering.ipynb` | Builds 4 candidate engineered features, measures each one's actual contribution via ablation (F1/ROC-AUC with vs. without) plus feature importance/correlation, and separately checks whether any of the 21 raw features are weak enough to drop — then saves the resulting feature set | `data/diabetes_sampled_final.csv`, `data/dropped_features.json` |
| `02_preprocessing.ipynb` | 80/20 stratified train/test split, StandardScaler on numeric columns, SMOTE-balanced training variant. Reads `diabetes_sampled_final.csv` or `diabetes_sampled.csv` depending on `config.USE_ENGINEERED_FEATURES` | `data/X_train*.csv`, `data/X_test.csv`, `data/y_train*.csv`, `data/y_test.csv` |
| `03_train_models.ipynb` | Trains Decision Tree, Naive Bayes, k-NN, Random Forest, and AdaBoost (required by course guidelines) on both original and SMOTE-balanced training sets (10 models), fixed hyperparameters | `data/models/*.pkl` |
| `03b_hyperparameter_tuning.ipynb` | Tunes the 5 required models plus adds XGBoost and LightGBM as extra candidates, using Optuna (TPE) scored on 5-fold CV F1, on both original and SMOTE-balanced training sets (14 studies) | `data/models/*_tuned.pkl`, `data/hyperparameter_tuning_summary.csv` |
| `04_evaluate_compare.ipynb` | Evaluates all fixed-hyperparameter and tuned models (including XGBoost/LightGBM) on the held-out test set: Accuracy, Precision, Recall, F1, ROC-AUC, confusion matrices, ROC curves | `data/model_comparison_results.csv`, `figures/confusion_matrix_*.png`, `figures/roc_curves_comparison.png` |
| `05_final_model_full_data.ipynb` | Reads the highest-F1 model/config from `model_comparison_results.csv`, rebuilds the same feature engineering, and retrains it on the full 253,680-row raw dataset (not just the 40k sample) to check whether more data improves generalization | `data/models/final_model_full_data.pkl`, `data/final_model_full_data_comparison.csv` |

Each notebook imports shared settings from `src/config.py` (random seed,
paths, sample size) — it must stay in the same folder as the notebooks so the
`from config import ...` cell works.

## Notes

- Sample size, test split ratio, and random seed are set in `src/config.py`.
- `config.USE_ENGINEERED_FEATURES` (default `True`) controls whether
  `02_preprocessing.ipynb` reads the engineered/feature-selected dataset from
  `01b_feature_engineering.ipynb` or falls back to the raw `01_eda.ipynb`
  sample with all 21 original features. Set to `False` to disable feature
  engineering entirely without deleting any notebook.
- The report, literature review, discussion, and AI-use declaration are the
  student's own work and are not generated by this codebase.
